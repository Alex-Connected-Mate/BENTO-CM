Guide : choisir le bon modèle Whisper AI pour la dictée

Par Alexandre Cormeraie2025-12-12

Better Dictate propose 4 tailles de modèle Whisper AI. Voici comment choisir le bon pour vos besoins.

Les 4 modèles

  • Tiny (~75 Mo) — ultra-rapide, bon pour les messages courts. Précision correcte.
  • Small (~500 Mo) — le meilleur équilibre. Recommandé pour la plupart des utilisateurs.
  • Medium (~1.5 Go) — haute précision. Idéal pour le contenu technique.
  • Large (~3 Go) — précision maximale. Pour les professionnels exigeants.

Notre recommandation

Pour 95% des utilisateurs, le modèle Small est parfait. Il offre une excellente précision avec un impact minimal sur les performances de votre Mac.

Tous fonctionnent en local

Quel que soit le modèle choisi, tout se passe sur votre Mac. Aucune donnée n'est envoyée à un serveur. C'est la philosophie Connected Mate.
