Politique de Confidentialite — Pock

Derniere mise a jour : Janvier 2026

Connected Mate ("nous", "notre") a developpe l'application Pock ("l'Application") en tant qu'application commerciale avec des achats integres optionnels. Cette page a pour but d'informer les utilisateurs de notre politique en matiere de collecte, d'utilisation et de divulgation des informations personnelles.

1. Donnees collectees

Pock ne collecte aucune donnee personnelle.

Toutes les informations financieres que vous saisissez dans l'application (montants, noms de comptes, objectifs, revenus, charges) sont stockees exclusivement sur votre appareil (iPhone, iPad, Apple Watch). Aucune de ces donnees n'est transmise a nos serveurs ou a des tiers.

2. Stockage des donnees

Les donnees sont stockees localement sur votre appareil via :

  • Le stockage local de l'application (UserDefaults, SwiftData)
  • Les App Groups pour la synchronisation entre l'application principale, les widgets et l'Apple Watch

Si vous utilisez iCloud, vos donnees peuvent etre synchronisees entre vos appareils Apple via le stockage iCloud prive d'Apple. Dans ce cas, les donnees sont chiffrees et gerees par Apple conformement a leur propre politique de confidentialite.

3. Donnees de paiement

Les achats integres (abonnement Pock Premium) sont traites exclusivement par Apple via l'App Store. Nous n'avons pas acces a vos informations de paiement (carte bancaire, identifiant Apple, etc.).

4. Services tiers

Pock utilise un seul service externe :

  • API Frankfurter (Banque Centrale Europeenne) : Pour obtenir les taux de change des devises. Cette API ne recoit aucune donnee personnelle de votre part. Seule une requete anonyme est envoyee pour obtenir les taux du jour.

5. Cookies et trackers

Pock n'utilise aucun cookie, aucun tracker, aucun outil d'analyse (pas de Google Analytics, pas de Firebase, pas de Mixpanel, etc.). Nous ne suivons pas votre utilisation de l'application.

6. Partage de donnees

Nous ne partageons, ne vendons et ne louons aucune donnee personnelle a des tiers. Nous n'avons tout simplement pas de donnees a partager puisque tout reste sur votre appareil.

7. Securite

Bien que nous ne stockions aucune donnee sur nos serveurs, nous prenons la securite de vos donnees locales au serieux :

  • Possibilite de proteger l'application par mot de passe
  • Support de Face ID et Touch ID
  • Floutage des montants pour la discretion

8. Droits des utilisateurs

Puisque vos donnees sont stockees localement, vous avez un controle total :

  • Acces : Toutes vos donnees sont visibles dans l'application
  • Modification : Vous pouvez modifier toutes vos donnees a tout moment
  • Suppression : Vous pouvez supprimer toutes vos donnees via Reglages > Reinitialiser les donnees, ou en desinstallant l'application
  • Portabilite : Vous pouvez exporter vos donnees en PDF (fonctionnalite Premium)

9. Enfants

Pock n'est pas destinee aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de donnees de mineurs.

10. Modifications de cette politique

Nous nous reservons le droit de modifier cette politique de confidentialite. Les modifications seront publiees sur cette page avec une date de mise a jour.

11. Contact

Pour toute question concernant cette politique de confidentialite :

  • Email : support@connectedmate.fr
  • Site web : https://connectedmate.fr
