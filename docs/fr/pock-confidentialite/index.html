Dernière mise à jour : janvier 2026.

Connected Mate (« nous », « notre ») a développé l'application Pock (« l'Application ») en tant qu'application commerciale avec des achats intégrés optionnels. Cette page a pour but d'informer les utilisateurs de notre politique en matière de collecte, d'utilisation et de divulgation des informations personnelles.

1. Données collectées

Pock ne collecte aucune donnée personnelle.

Toutes les informations financières que vous saisissez dans l'application (montants, noms de comptes, objectifs, revenus, charges) sont stockées exclusivement sur votre appareil (iPhone, iPad, Apple Watch). Aucune de ces données n'est transmise à nos serveurs ou à des tiers.

2. Stockage des données

Les données sont stockées localement sur votre appareil via :

  • le stockage local de l'application (UserDefaults, SwiftData) ;
  • les App Groups pour la synchronisation entre l'application principale, les widgets et l'Apple Watch.

Si vous utilisez iCloud, vos données peuvent être synchronisées entre vos appareils Apple via le stockage iCloud privé d'Apple. Dans ce cas, les données sont chiffrées et gérées par Apple conformément à sa propre politique de confidentialité.

3. Données de paiement

Les achats intégrés (abonnement Pock Premium) sont traités exclusivement par Apple via l'App Store. Nous n'avons pas accès à vos informations de paiement (carte bancaire, identifiant Apple, etc.).

4. Services tiers

Pock utilise un seul service externe : l'API Frankfurter (Banque Centrale Européenne), pour obtenir les taux de change des devises. Cette API ne reçoit aucune donnée personnelle de votre part. Seule une requête anonyme est envoyée pour obtenir les taux du jour.

5. Cookies et trackers

Pock n'utilise aucun cookie, aucun tracker, aucun outil d'analyse (pas de Google Analytics, pas de Firebase, pas de Mixpanel, etc.). Nous ne suivons pas votre utilisation de l'application.

6. Partage de données

Nous ne partageons, ne vendons et ne louons aucune donnée personnelle à des tiers. Nous n'avons tout simplement pas de données à partager puisque tout reste sur votre appareil.

7. Sécurité

Bien que nous ne stockions aucune donnée sur nos serveurs, nous prenons la sécurité de vos données locales au sérieux :

  • possibilité de protéger l'application par mot de passe ;
  • support de Face ID et Touch ID ;
  • floutage des montants pour la discrétion.

8. Droits des utilisateurs

Puisque vos données sont stockées localement, vous avez un contrôle total :

  • Accès : toutes vos données sont visibles dans l'application.
  • Modification : vous pouvez modifier toutes vos données à tout moment.
  • Suppression : vous pouvez supprimer toutes vos données via Réglages > Réinitialiser les données, ou en désinstallant l'application.
  • Portabilité : vous pouvez exporter vos données en PDF (fonctionnalité Premium).

9. Enfants

Pock n'est pas destinée aux enfants de moins de 13 ans. Nous ne collectons pas sciemment de données de mineurs.

10. Modifications de cette politique

Nous nous réservons le droit de modifier cette politique de confidentialité. Les modifications seront publiées sur cette page avec une date de mise à jour.

11. Contact

Pour toute question concernant cette politique de confidentialité : support@connectedmate.fr.
